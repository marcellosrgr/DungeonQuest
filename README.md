# DungeonQuest: Math Mage Survivor 🧙‍♂️✨

An action roguelite survival / beat 'em up web game combining fast-paced arena combat with rapid mental math challenges. Built with Pure Vanilla JavaScript, HTML5 Canvas 2D API, and Web Audio API synthesis (Zero external asset dependencies).

---

## 🎮 Features

- **Action Roguelite Combat**: Dodge swarming dungeon monsters (slimes, goblins, skeletons, shadow beasts) across 10 progressive survival waves.
- **Adaptive Math Engine**: 3 difficulty levels (Basic Arithmetic, Fast Multiplication/Division, and Simple Algebra).
- **Zero MP3 / Pure Web Audio Synth**: Synthesizes all spell cast sounds, hits, explosions, answer chimes, penalty buzzers, and procedural background bassline in real-time.
- **Dynamic Visual Feedback**: Particle explosions, floating damage & combo text, hit flashes, screen shakes, and arcane neon dark-mode UI.
- **Dual Control System**: Responsive keyboard controls (`WASD` + Hotkeys `[1]-[4]`) and mobile touch controls (Virtual D-Pad + On-screen Spell Cards).
- **Game Over & Victory Reports**: Tracks accuracy percentage, highest combo streak, and average response speed.

---

## 🕹️ Controls

| Action | Keyboard | Touch / Mobile |
| :--- | :--- | :--- |
| **Move Mage** | `W` `A` `S` `D` or Arrow Keys | Virtual D-Pad (Bottom Left) |
| **Cast Spell** | Keys `[1]`, `[2]`, `[3]`, `[4]` | Tap Spell Answer Cards |
| **Mute/Unmute** | Click Sound Icon 🔊/🔇 | Tap Sound Icon |

---

## 🚀 How to Run Locally

Simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/marcellosrgr/DungeonQuest.git
cd DungeonQuest
# Open index.html in your browser
```
